# Machine poster

`machine-poster.webp` is a render of the shipped 3D viewer, not an illustration. It was captured
on 2026-11-26 from `/concepts/machine/` on the docs build of main `8916c209`: headless Chrome with
SwiftShader WebGL at a 1600x1000 viewport and device scale 2, after "Start the 3D machine",
with the viewer's overlays hidden and its zone and lane labels kept, then encoded as WebP
(quality 78).

Re-capture it when the machine's parts, zones or lane labels change visibly, so the landing's
poster keeps matching the viewer it links to.
