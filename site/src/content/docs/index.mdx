    <p>codeArbiter routes intent into the lane that owns it, scales the gates to the risk, and leaves a resumable record on disk.</p>

  </div>
  <ol class="ca-flow__steps" role="list">
    <li class="ca-flow__step">
      <span>1</span>
      <div>
        <h3>State the work</h3>
        <p>Feature, fix, sprint, dependency, decision, review, or release.</p>
      </div>
    </li>
    <li class="ca-flow__step">
      <span>2</span>
      <div>
        <h3>Clear the lane</h3>
        <p>Specs, tests, reviewers, and security checks appear only when the change needs them.</p>
      </div>
    </li>
    <li class="ca-flow__step">
      <span>3</span>
      <div>
        <h3>Ship through a PR</h3>
        <p>Commit evidence and review state travel with the branch. The default branch is never a direct write.</p>
      </div>
    </li>
  </ol>
</section>

<section class="ca-section ca-fit" aria-labelledby="ca-fit-title">
  <div class="ca-fit__copy">
    <p class="ca-eyebrow">Fit before friction</p>
    <h2 id="ca-fit-title">Built for work that has to remain explainable.</h2>
    <p>codeArbiter adds deliberate process. That pays off when the repository outlives the current session, more than one person or host touches it, or a security and delivery claim needs evidence.</p>
  </div>
  <div class="ca-fit__columns">
    <div>
      <h3>Use it when</h3>
      <ul>
        <li>agents implement meaningful product work;</li>
        <li>decisions and bypasses need attribution;</li>
        <li>tests and reviews must be real stops;</li>
        <li>the same project moves between supported hosts.</li>
      </ul>
    </div>
    <div>
      <h3>Skip it when</h3>
      <ul>
        <li>the code is a disposable one-hour experiment;</li>
        <li>any process friction is unacceptable;</li>
        <li>the repository cannot carry a checked-in state directory.</li>
      </ul>
    </div>
  </div>
