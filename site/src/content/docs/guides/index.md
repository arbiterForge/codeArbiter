Start with the job, not the internal role names. You can describe your intent naturally or use the
explicit host entries shown by each guide. Clear intent does not replace an approval required by
the owning lane.

## Initialize and understand

[Opt a repository in](/guides/opt-in-a-repo/), then follow either
[Plan a new project](/guides/plan-a-new-project/) or
[Understand an existing project](/guides/understand-an-existing-project/).
Finish by [proving enforcement](/getting-started/quickstart/).

## Make a change

Follow [Your first feature](/guides/first-feature/) for one complete example.
Use [Build a feature end to end](/guides/feature-lane/) for the full lane,
[Review specifications and plans](/guides/review-artifacts/) at the human review boundary,
and [Run an autonomous sprint](/guides/autonomous-sprints/) when the approved scope can proceed
without attended batch checkpoints.

## Review and ship

[Add a dependency safely](/guides/adding-a-dependency/),
[record an architecture decision](/guides/recording-adrs/), or
[cut a release of your project](/guides/releasing-a-version/).
The command references for [review](/reference/commands/review/),
[commit](/reference/commands/commit/) and [PR](/reference/commands/pr/) describe their precise
boundaries; the first-feature example connects them.

## Operate and recover

[Return to a project](/guides/return-to-a-project/) for status and task selection.
[Resume and recover](/guides/resume-and-recover/) when an existing run stopped.
Use [Troubleshooting](/guides/troubleshooting/) for installation and capability failures,
[Override a gate safely](/guides/overriding-a-gate/) only for a justified sanctioned exception,
and [Uninstall and disable](/guides/uninstalling/) for an intentional exit.
[Set up the statusline](/guides/the-statusline/) after understanding the state it displays.

## Practice and advanced tooling

[Arbiter Academy](/academy/) provides prepared, verifier-backed exercises with their own
prerequisites. [Feature Forge](/feature-forge/overview/) explains preview maturity.
[ca-sandbox](/guides/ca-sandbox/) is separate infrastructure, not a governance adapter.
