A coding agent is a language model inside a loop that can run tools. The model writes the most
likely next text, and some of that text is a request to act: run a command, edit a file, push a
branch. A likely request is not a checked one, so something outside the model has to decide what is
allowed to run. In codeArbiter, that decision belongs to plain programs called hooks, to lanes that
give each kind of work its own route, and to you.

## The mental model

This page lays the whole system out as one machine. Every part is either a concept from AI
inference or a codeArbiter component, and every lane is one command's route.

- **The model** sits at the center. It turns text into tokens, predicts a probability for every
  possible next token, and samples one. Repeating that writes every sentence and every tool call.
- **The agent harness** (Claude Code, Codex CLI or Pi) reads the model's output, recognizes tool
  calls, and runs the tools it allows.
- **The guard ring** is codeArbiter's enforcement core. Its hooks check each tool call before it
  runs and refuse the ones that break a hard rule, the same way every time.
- **Routing, skills and agents** decide which lane owns a request and which specialist helpers it
  calls in.
- **The record** is what outlives the session: plans, decisions, the audit log and evidence.
- **You** start the work and keep the decisions the machine cannot make: requirements,
  architecture, merges and releases.

## What this changes in daily use

- A `BLOCKED [H-xx]` line names its gate. Look it up in [Hook Gates](/reference/hooks-gates/) to
  see every message that gate can print and the source line that prints it.
- A `REMINDER [H-xx]` line is advisory: the call goes ahead, and the reminder is not written to
  `gate-events.log`. Some reminders come before a blocking gate, such as H-10 after a write that
  looks like a secret and H-10b when that change is committed.
- The model's text is a sample, so the same request can produce a different plan. The gates
  respond to the action that reaches them, whatever wording produced it.
- When a lane stops and asks you, the question is the product working as designed. An answer from
  you is the authorization the model cannot give itself.
