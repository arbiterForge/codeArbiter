Getting around

Every part of the machine is either an AI concept or a piece of codeArbiter. Select any part to read about it; select a lane and press Run to watch its route.

Orbit
Drag with one finger or the left mouse button
Pan
Right-drag, or drag with two fingers
Zoom
Scroll or pinch; zoom follows the pointer
Select a part
Click it or its label; double-click to fly closer
Labs
Hands-on: break things on purpose, try to get past a guard, roll the model’s dice
Dotted words
Hover or tap a word with a dotted underline for a plain definition
Tours
T opens them; ← → step, Space autoplays, Read aloud speaks each stop
Search
/ jumps to the parts search
View
R reset, F focus the selected part, L labels, M motion
Close
Esc closes the panel or tour
Example session
Plays a scripted agent session through the machine. It is slowed down so you can follow each step.

How to read the machine

Like a map, every mark means one thing wherever it appears. Shape says what kind of thing a part is. Colour says what is happening to it right now. Each kind of motion has one meaning.

Shape: what kind of thing it is

Colour: what is happening

Motion: what it means

The example session shown above the model is scripted. Its token splits, probabilities and attention weights are illustrative. The order of events, the hook tags and the rule that every shell or write block is appended to gate-events.log follow codeArbiter’s source.
