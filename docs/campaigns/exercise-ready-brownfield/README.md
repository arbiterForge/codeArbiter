2. **Correct onboarding and refresh.** Preserve initialization; validate file-specific invariants before the completion marker; recover partial work; preserve existing instruction/record owners; normalize evidence and make failures/coverage explicit.
3. **Reuse existing context before generating more.** Keep the coarse map, per-document provenance, task-time retrieval and advisory read injection. Correct per-document healing, freshness coverage, bounded size and delivery to the actual author/reviewer.
4. **Evaluate an optional governed guidance pilot.** Compare it against the improved map-only baseline. Use the existing engine, one canonical record and deterministic native Markdown views only when placement, authority, ownership, freshness and host qualification justify them. Default off; zero new files and rejection of the idea are valid outcomes.
5. **Bound greenfield reuse.** Acquire actual facts after meaningful scaffolding/implementation; do not invent nested policies for an empty repository or redesign greenfield as a side effect.
