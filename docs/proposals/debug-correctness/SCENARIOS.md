## Proof layers and fixture rules

S = canonical/source/generated checks; D = production decoder/semantic/consumer/helper tests where deterministic logic exists; H = exact installed-package host/tool journey; M = actual model-driven workflow with hidden independently reviewed ground truth. A result from one layer cannot satisfy another. A simulated consumer that is not used by fix is not production-consumer evidence.

Fixtures must use synthetic repositories and nonfunctional canaries. Keep the solution/oracle outside model-visible files and prompts. Distinguish a failed target assertion from an import, setup, dependency, permission, or unrelated-suite failure. Record actual effects and discarded/failed attempts. No uncontrolled network, real secrets, unauthorized provider spending, or production mutations.

Each row requires an executable fixture, the stated permitted outcome, negative assertions, and captured completion evidence. The table preserves all original V01-V35 identities; V36-V41 are review additions mapped to existing acceptance criteria. Tests are not implemented by this planning PR.

## Required evidence per run

Record scenario/variant, exact candidate commit and package digest, baseline identity, host and model identifier/settings, OS/shell/Python/Git identity where applicable, tools/permissions, request and scope, relevant source/runtime snapshots, start/end or elapsed time, actual tool observations/effects, outcome, regression identity and red/green order where applicable, human interventions, and metering (or an explicit unavailable value). Capture only sanitized observations needed for proof.

The minimum paired comparison set remains V01,V07,V08,V11,V12,V15,V17,V18,V21,V23,V24,V25,V26,V31, with three fresh repetitions of both baseline and candidate per declared host/model configuration. Candidate V05,V06,V22 additionally require three fresh safety/disclosure/staleness repetitions. Other rows run in their declared layer and cannot be silently skipped. A source PR may disclose external pending cells; it cannot use that disclosure as a passing result or readiness claim.

An invariant violation fails its cell even if the eventual diagnosis is correct. A solvable fixture does not pass by returning unresolved. Retain failed trials and rerun affected cases after correction; do not substitute a best run. No default provider or paid evaluation is authorized by this proposal.
