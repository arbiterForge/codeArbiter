## T02/T06 source adversarial pass

Even complete criterion-to-task mapping can pass while the real fix consumer ignores the handoff, a solvable model case escapes unresolved, or an evaluator solution leaks into the solver context. The freeze therefore keeps actual consumer/host/model evidence separate and makes allowed dispositions variant-specific. Evaluator-side metadata must remain outside the synthetic solver checkout and accessible tools. Any detected solution leakage invalidates that trial; a private filename alone is not isolation.

The numeric contract was incomplete without rounding-sensitive controls: default float parsing can turn 1e-4000 into zero or a long fractional number into an integer. D1 freezes exact decimal meaning without an arbitrary new numeric range or exponent-sized allocation. Timestamp support is an explicit subset rather than an unqualified RFC3339 claim. Unknown-offset -00:00 remains distinguishable from a known local offset. Scalar counts and UTF-8 byte counts are separate.

The optional fingerprint could accidentally become an expensive new prerequisite or false proof. Initial production is explicitly omitted; retained pairs never bypass targeted source/index/runtime checks. No generic recipe executor, hash subsystem or persistent case store is added.

A no-effect validator cannot promise an envelope after process death or broken stdout. The normal envelope and abnormal caller behavior are now explicit. Unknown input keys cannot enter diagnostic paths and leak rejected data. The helper does not gain process-supervision or authority duties merely to make a negative test pass.

A matrix mapping SEM rules to D checks alone would overclaim causality, disclosure safety, permissions and currentness. D1-CASES.json names D/H/M boundaries separately; hostile-looking inert text is not automatically rejected if structurally valid. Correct acceptance with zero effects is an essential positive control.

No further missing user-owned product requirement was identified in the source-only scope pass. That is not a finding of zero runtime defects or an independent review receipt. Native review and executable fixtures can still reject this design.
