## All findings (full detail)

### Security

#### HIGH — candidate-owned CI provenance verifier

`.github/workflows/ci.yml` executes the candidate-owned provenance verifier and tests in `codex-candidate-provenance` instead of executing a trusted default-branch verifier against inert candidate data. A candidate can therefore alter the verifier that evaluates that same candidate. Use a separate trusted checkout and add a regression with a fake candidate verifier.

Disposition: **BLOCKS**.

#### HIGH — incomplete hook schema and command grammar

`.github/scripts/check_codex_skill_resources.py` searches only a hook-command substring or first root target and does not validate the complete schema or an anchored allowlisted command grammar. Prefixed or appended external commands and missing later targets can pass. Require a supported schema and exactly one approved, contained hook target invoked through the exact supported interpreter; add adversarial regressions.

Disposition: **BLOCKS**.

#### MEDIUM — ambiguous metadata parsing and version shape

Ordinary JSON and front-matter parsing accepts duplicate or ambiguous members; version validation accepts non-SemVer and malformed scalar quoting. Use strict duplicate-member and nonfinite-value JSON parsing, reject duplicate front-matter keys, enforce the repository's SemVer contract, and add malformed-scalar regressions. Coverage-auditor independently reported the same contract gap, so triage consolidated it as one unique finding.

Disposition: **DEFERRABLE**.

#### MEDIUM — resource bounds applied after or absent from reads

The verifier reads an entire ZIP before applying the 8 MiB limit, while directory candidate enumeration has no entry-count, per-file, or aggregate-size limits. Enforce bounds before reads, hash incrementally, and add refusal regressions.

Disposition: **DEFERRABLE**.

### Coverage / Test Audit

#### MEDIUM — ambiguous metadata parsing and version shape

Ordinary JSON and front-matter parsing accepts duplicate or ambiguous members; version validation accepts non-SemVer and malformed scalar quoting. Use strict duplicate-member and nonfinite-value JSON parsing, reject duplicate front-matter keys, enforce the repository's SemVer contract, and add malformed-scalar regressions. #### MEDIUM — includes front-matter specification mismatch

The static candidate contract and tests omit `includes/*.md` front matter even though the approved specification requires it, with neither enforcement nor a documented exemption. Enforce the requirement or reconcile the specification and test the narrow exemption.

Disposition: **DEFERRABLE**.

#### MEDIUM — missing expected-digest and generated-drift regressions

Provenance tests prove repeatability but do not prove rejection of an expected archive, package, or resource digest mismatch or generated-surface drift. Add mutation and canonical-parity regressions.

Disposition: **DEFERRABLE**.
