Exercise-ready brownfield onboarding and reusable repository context

Make the path from an unfamiliar fork to a trustworthy first contribution reliable, then reduce repeated exploration with maintained, task-relevant context. Correct lifecycle and existing-map reuse first. Scoped host instruction generation is a conditional, default-off experiment that must justify its cost and preserve authority. This is one unapproved campaign specification, not implementation or release evidence.

DEC-LIMITS

Authorityproposed
ChoiceMaximum 64 KiB UTF-8 per scout report, 128 evidence entries/report, 20 KiB code map, 50 coarse map entries, 2 KiB per managed guidance view and 8 KiB cumulative task guidance including imports. RationaleClosed bounds prevent context explosions; oversize is explicit subdivision/selection, never silent truncation. These initial values require comparative evaluation, not invented token equivalence.
