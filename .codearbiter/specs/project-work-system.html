Project work system — unified work, brownfield planning and human views

One assistive work interface, durable identities, shared greenfield/brownfield records and outcome-oriented HTML. Deliver local tracking plus GitHub first; preserve real permissions without inventing a second permission system. Proposed implementation, not released behavior.
