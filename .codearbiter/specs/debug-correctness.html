Intent

INTENT-01

Intent

CallerA maintainer or contributor diagnosing an identifiable failure through codeArbiter debug and, when separately authorized, continuing into fix/TDD.
OutcomeA truthful diagnosis or actionable unresolved result with cited current evidence, followed by a bounded validated handoff that preserves caller authority, TDD target-red proof, host parity, and all existing governance gates.
ProblemThe current debug procedure can block useful investigation, force unresolved evidence into false dispositions, conflate experiments with confirmation, mutate task state for no-action outcomes, underspecify the bug-origin handoff to fix/TDD, and emit a helper invocation that is not portable to ordinary Codex tool calls.

2. Primitive profile

Blocks

- `text(N)`: Unicode string with at least one non-whitespace character and at most N Unicode code points. No unpaired surrogate code points. Leading/trailing text is preserved, not silently repaired. - `nullable(T)`: T or null, never an omitted required field. - `refs(P,N)`: array of distinct identifiers of namespace P; minimum zero and maximum N unless a semantic rule requires a member. - Namespace identifiers are full-string matches: `S-`, `E-`, `H-`, or `C-`, followed by 2-4 ASCII decimal digits. Blocks
